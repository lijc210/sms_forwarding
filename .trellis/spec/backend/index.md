# 后端开发规范

> sms-forwarding 后端编码约定。

---

## 架构概述

后端是一个单进程 FastAPI 应用，使用异步串口通信。无数据库、无 ORM、无外部服务依赖。所有状态均在内存中，或通过 AT 命令从 ML307A 模组实时查询。

## 关键设计决策

- **无数据库**：模组状态缓存在内存中，设备始终是数据源。
- **双文件后端**：`at_serial.py` 负责串口协议；`main.py` 负责 Web 框架。如果后续添加 CLI 或其他前端，AT 协议层可直接复用。
- **后台轮询替代 WebSocket**：模组状态每 8 秒轮询，短信缓存每 15 秒轮询。避免常驻串口监听线程。
- **`asyncio.Lock` 保护串口访问**：防止 API 处理程序和后台任务在同一个串口上交错发送命令。
